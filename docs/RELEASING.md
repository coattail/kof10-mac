# 发布步骤

1. 确认游戏、BIOS、模拟器、图标、微软运行库，以及所有 Wine 依赖的可分发范围；补齐相应许可与对应源码。本次游戏内容由发布者确认授权；公共包使用 --download-runtime，Wine 二进制由玩家直接从上游取得，不再包含在 Release 中。
2. 使用独立、干净的本地游戏输入目录运行 `scripts/build.py`。不要从个人 Wine Prefix 打包运行日志、注册表、凭据或个人存档。
3. 使用 `scripts/package.py` 生成 ZIP、SHA256SUMS 和 bundle-manifest.json。脚本验证签名、最低版本，并拒绝日志和调试映像。
4. 在全新的独立游戏环境验证第一次启动、载入游戏、显示比例、退出与保存。保留验证范围；不能把单机结果表述为所有 Mac 和控制器均可用。
5. 有 Developer ID 与公证凭据时，可自行签名与公证。本项目不附带签名凭据或账号密钥。
6. 用仓库标签创建 GitHub Release，上传 ZIP、校验值、清单和许可证要求的源码。公开前检查附件和说明。源码仓库不提交大体积应用、ROM 或用户数据。
7. 从匿名 GitHub 下载入口验证可下载性，并核对下载后的 SHA-256。
