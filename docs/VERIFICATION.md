# v1.0.3 易用性验证

验证日期：2026-10-10。环境：Apple Silicon，macOS 27.0.1，已安装 Rosetta。

- 独立、初始为空的测试环境自动下载并校验运行组件；原生窗口显示实际下载百分比。
- 自动初始化后直接载入拳皇 2002，观察到正常动态图像，没有经过 File → Load game。
- 通过原生中文窗口从运行中的游戏切换到拳皇 97，再切回拳皇 2002；旧进程按正常关闭路径退出，状态为 0。
- 正常退出后再次打开，自动载入上次在中文窗口选择的版本。
- 在测试包中临时模拟准备失败（退出码 20），出现中文“重试”按钮；恢复真实准备脚本后，点击重试成功进入游戏。此测试替换不包含在发布包中。
- 检查完整的中文游戏选择窗口，标题、十个版本按钮和操作提示均可见。
- 按 2 投币、1 开始进入拳皇 2002 模式选择画面，J 可以确认选择。
- 关闭游戏辅助程序仅导入 KERNEL32 和 USER32，不额外要求 C/C++ 运行库。

没有在缺少 Rosetta 的机器上实测安装引导；没有可用 Developer ID 证书，尚未公证。其他机器的首次安全确认、全部系统版本、全部 ROM 实战和控制器限制见[兼容性说明](COMPATIBILITY.md)。

# v1.0.2 发布验证

验证日期：2026-10-10。实际运行环境：Apple Silicon，macOS 27.0.1，已安装 Rosetta。

## 已完成的检查

- 从仓库源码重新编译 Mac 启动器与 Windows 显示组件。
- 使用独立测试目录，初始没有运行时缓存或 Wine 游戏环境。
- 首次启动从固定上游下载 Wine 11.0_1，并通过 SHA-256 校验。
- 自动初始化新的 Wine 环境，加载随包的 Visual C++ 依赖与游戏文件。
- 载入拳皇 2002，观察到正常彩色、动态游戏画面；关闭游戏后退出状态为 0。
- 再次启动使用运行时缓存，仍能正常载入拳皇 2002。
- 原生启动器部署目标与应用最低系统版本均为 macOS 11.0。
- GitHub [Source checks](https://github.com/coattail/kof10-mac/actions/workflows/check.yml) 编译检查通过。

验证游戏载入时临时传入 `kof02x` 命令行参数；发布包已恢复默认启动行为，通过 File → Load game 选择游戏。测试目录、注册表、日志和测试应用标识不包含在发布包内。

## 验证边界

这是本机新环境验证，不代表其他 Mac 的首次安全检查、所有系统版本或全部游戏均已验证。现有用户已确认拳皇 2002 可游玩。手柄、双人、联机、全部 ROM 和音频细节的限制见[兼容性说明](COMPATIBILITY.md)。
