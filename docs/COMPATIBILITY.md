# 兼容性与验证范围

## 已验证

- 本机原 Windows 游戏目录曾有 MFC42 缺失、保护壳崩溃和全黑画面问题。
- 原生 arm64 启动器显式指定 `arm64-apple-macosx11.0`，同时保持 plist 最低系统版本 11.0。
- 使用者确认修复后可以实际游玩拳皇 2002。
- GDI 显示组件在窗口拖动时保留渲染线程，按实际客户区尺寸更新视口，保持 4:3。
- 原版 16×16、32×32 彩色地球图标按原像素生成 ICNS。
- 发布包在独立、初始为空的游戏环境中完成运行时下载、校验、初始化、拳皇 2002 画面显示和缓存再启动验证；见[发布验证记录](VERIFICATION.md)。

## 尚未验证或仍有问题

- GP2040-CE D-Input：系统与 Wine 可以枚举设备，但实体按键录入失败仍未解决。`no_dinput_hook=true` 的尝试没有解决使用者报告的问题。
- 其他控制器、全部游戏的逐一实战、双人、联机、全屏和所有音频细节。
- macOS 11–26 的每个系统版本、Intel Mac、macOS 28。
- 其他 Mac、网络下载后的 Gatekeeper 首次启动和机器间迁移。
